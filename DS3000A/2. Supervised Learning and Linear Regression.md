## Supervised Learning

### Definition

Suppose each observation is a data point $(x, y)$, collected together into a dataset $\mathcal{D}$. The **goal** of supervised learning is: given a new input $x_{\text{new}}$, predict the corresponding $y_{\text{new}}$.

The **how**: find a function $f : x \mapsto y$ that **fits** $\mathcal{D}$ well, meaning:
- Note: we define $\mathcal{D} = {(x_n, y_n)}_{n=1}^N$ 

1. For each $(x, y) \in \mathcal{D}$, the value $f(x)$ should be close to $y$ (fits what we've already seen).
2. The function should also be able to predict $y_{\text{new}}$ well from $x_{\text{new}}$ (generalizes to new data).

> If we only have $x$ (no labels $y$), the problem becomes **unsupervised learning** instead — there is no "correct answer" to fit against.

**Intuition examples from the slides:**

- Image classification: 🦆 → duck, 🐕 → cat, 🐈 → cat, 🐶 → **?** (the function should generalize to a new, unseen image).
- Sequential/numeric pattern: 9 AM → 21, 10 AM → 25, 11 AM → 30, 12 PM → **?** (the function should extrapolate a trend).

This is the core theme of the course: recognize patterns in existing data to make predictions on new data, in order to make decisions.

### Regression as a Special Case

Suppose $\boldsymbol{x} \in \mathbb{R}^D$ (a $D$-dimensional input) and $y \in \mathbb{R}$ (a single real-valued output). Finding an $f$ to fit $\mathcal{D}$ in this setting is called a **regression** problem — i.e., regression is supervised learning where the target is continuous rather than categorical (contrast with _classification_, where $y$ takes discrete/categorical values).

**Examples:**

- $x = \text{time}$; $y = \text{temperature}$.
- $x = \text{item}$; $y = \text{price}$.
- $x = \text{study effort}$; $y = \text{grade (0–100)}$.
- $x = \text{GPS coordinates}$; $y = \text{elevation}$.
	- For example: $f(\begin{bmatrix} 43°00'27.58^"N &&81°16'21.32^"W\end{bmatrix})=250m$ 

## The General Recipe for Supervised Learning

Finding a function $f$ that fits $\mathcal{D}$ well always follows the same three-step recipe:

1. **Choose a form for the function** that relates $x$ to $y$.
2. **Define a measurement of loss**: "how badly a function fits $\mathcal{D}$."
3. **Find a function** in that class/form that is **least bad** (i.e., minimizes the loss).

The rest of the lecture works through these three steps concretely for linear regression.

## Step 1: Choosing a Function Form

### Parametric Functions

Rather than searching over _all_ possible functions (an intractable space), we restrict ourselves to a **parametric function**:

$$f(\boldsymbol{x}; \boldsymbol{\theta})$$

where $\boldsymbol{\theta}$ is the **parameter** (or vector of parameters). Different values of $\boldsymbol{\theta}$ yield different functions within the same family — so "learning" becomes a search over $\boldsymbol{\theta}$ rather than over arbitrary functions. (There are non-parametric approaches too, e.g. k-nearest-neighbours, but this course focuses on parametric ones.)

_Simple example:_ with $x \in \mathbb{R}$ and $\theta \in \mathbb{R}$, let $f(x;\theta) = \theta x$. Different scalar values of $\theta$ (e.g. $-1$, $0.5$, $1.2$) sweep out a whole family of lines through the origin.

### Linear Regression: One-Dimensional Input

Assume $\mathcal{D} = {(x_n, y_n)}_{n=1}^N$ with $x_n \in \mathbb{R}$, $y_n \in \mathbb{R}$. Let $\boldsymbol{\theta} = [\theta_1, \theta_2]^\top \in \mathbb{R}^2$ and define:

$$f(x; \boldsymbol{\theta}) = \theta_1 x + \theta_2.$$

Here $\theta_1$ is the slope and $\theta_2$ is the intercept. The key property: $f(x;\boldsymbol{\theta})$ is **linear in $\boldsymbol{\theta}$** — this is precisely what makes it "linear regression" (it does _not_ require $f$ to be linear in $x$; see the Basis Functions section below, where $x$ enters nonlinearly but $\boldsymbol{\theta}$ still enters linearly).

#### The Bias Trick

We can rewrite the line equation using vector operations:

$$f(x;\boldsymbol{\theta}) = \begin{bmatrix}\theta_1\\ \theta_2\end{bmatrix}^\top \begin{bmatrix}x\\1\end{bmatrix} = \boldsymbol{\theta}^\top \hat{\boldsymbol{x}}.$$

The trick is to **augment** the input with a constant $1$, giving $\hat{\boldsymbol{x}} = [x, 1]^\top$. This folds the intercept term $\theta_2$ into a plain dot product, so the whole model — slope _and_ intercept — is written as a single matrix-vector multiply. This simplifies both the math (Step 3 below) and the code:

```python
import numpy as np

def f(x, theta_1, theta_2):
    return theta_1 * x + theta_2

def f(x, theta):
    return theta[0] * x + theta[1]

def f(x, theta):
    return theta @ np.array([x, 1])
```

All three implementations are equivalent — they're just different ways of writing the same computation.

### Linear Regression: Multidimensional Input

Now let $\boldsymbol{x} \in \mathbb{R}^D$ and $y \in \mathbb{R}$. Define a **weight vector** $\boldsymbol{w} \in \mathbb{R}^D$ and a **bias/intercept** $b \in \mathbb{R}$, and let:

$$\boldsymbol{\theta} = \begin{bmatrix}\boldsymbol{w}\\b\end{bmatrix} \in \mathbb{R}^{D+1}.$$

Applying the bias trick with $\hat{\boldsymbol{x}} = \begin{bmatrix}\boldsymbol{x}\\1\end{bmatrix} \in \mathbb{R}^{D+1}$, :

$$f(\boldsymbol{x};\boldsymbol{\theta}) = \boldsymbol{\theta}^\top \hat{\boldsymbol{x}}.$$

Geometrically, for $D=2$ this is no longer a line but a **plane** (in general, a hyperplane) fit through the data points in $(x_1, x_2, y)$-space.

>Note on $\hat{x}$: if $\boldsymbol{x}=[x_1,...,x_D]^\top$ is a data point's raw features, then $\boldsymbol{\hat{x}}=[x_1,...,x_D,1]^\top$ 

>[!tip] The above is really just saying that for some input $x$ with $D$ features, take the dot product of the given weights $\boldsymbol{w}$ and multiply them with the relevant feature, then add them all together. The bias factor $\boldsymbol{b}$ is multiplied by the 1 at the end of $\boldsymbol{\hat{x}}$ and appears in the final sum. 

## Step 2: Defining a Measure of Fit (Loss Functions)

### What Is a Loss Function?

Given $\mathcal{D} = {(\boldsymbol{x}_n, y_n)}_{n=1}^N$ and a function form $f(x;\boldsymbol{\theta})$, the open question is: **which value of $\boldsymbol{\theta}$ should we choose?** Visually, infinitely many candidate lines/planes could be drawn through roughly the same cloud of points — we need a principled way to rank them.

A **loss function** measures how _badly_ $f(\boldsymbol{x}_n;\boldsymbol{\theta})$ approximates $y_n$, for each $n = 1, \dots, N$ — i.e., it measures how badly the choice of $\boldsymbol{\theta}$ fits $\mathcal{D}$ as a whole. Notation: $\mathcal{L}(\boldsymbol{\theta}; \mathcal{D})$, taking values in $\mathbb{R}$ (lower = better fit).

### Common Loss Functions for Linear Regression

Let $\mathcal{D} = {(\boldsymbol{x}_n, y_n)}_{n=1}^N$ and $f(\boldsymbol{x};\boldsymbol{\theta}) = \boldsymbol{\theta}^\top \hat{\boldsymbol{x}}$ (with $\boldsymbol{x} \in \mathbb{R}^D$, $y \in \mathbb{R}$, $\boldsymbol{\theta} \in \mathbb{R}^{D+1}$).

**Squared error** (the classic choice, used in _Ordinary Least Squares_, OLS):

$$\mathcal{L}(\boldsymbol{\theta}; \mathcal{D}) = \frac{1}{2}\sum_{n=1}^N \big(f(\boldsymbol{x}_n;\boldsymbol{\theta}) - y_n\big)^2$$

**Absolute error** (an alternative):

$$\mathcal{L}(\boldsymbol{\theta}; \mathcal{D}) = \frac{1}{2}\sum_{n=1}^N \big|f(\boldsymbol{x}_n;\boldsymbol{\theta}) - y_n\big|$$

> **Context (not explicit on the slides, but useful for intuition):** squared error penalizes large residuals disproportionately more (an error of 4 contributes 16x vs. an error of 1's contribution of 1), so it's sensitive to outliers but has the major practical advantage of being smooth/differentiable everywhere — enabling the closed-form solution derived in Step 3. Absolute error is more robust to outliers but is _not_ differentiable at zero, so minimizing it generally requires different tools (e.g. linear programming or subgradient-based methods) rather than the simple "set derivative to zero" approach used below.

## Step 3: Finding a Least-Bad Function

### General Approach

Given the loss $\mathcal{L}(\boldsymbol{\theta}, \mathcal{D})$, finding the least-bad $f(\boldsymbol{x};\boldsymbol{\theta})$ reduces to finding the $\boldsymbol{\theta}$ that **minimizes** $\mathcal{L}(\boldsymbol{\theta}, \mathcal{D})$. From calculus, the standard approach is: take the derivative (gradient, in the multivariate case) and set it to zero. This works directly here because the squared-error loss is a smooth, convex (bowl-shaped) function of $\boldsymbol{\theta}$ — visualized on the slides as concentric contour ellipses with a single global minimum.

### Linear Algebraic Formulation

To solve for all $N$ data points simultaneously, arrange the inputs into a matrix. Stack the $x_{nd}$'s into:

$$\boldsymbol{X} = \begin{bmatrix}x_{11} & \cdots & x_{1D}\\x_{21} & \cdots & x_{2D}\\ \vdots & & \vdots \\ x_{N1} & \cdots & x_{ND}\end{bmatrix} \in \mathbb{R}^{N\times D}.$$

Apply the bias trick to the whole matrix (append a column of ones):

$$\boldsymbol{\hat{X}} = \begin{bmatrix}x_{11} & \cdots & x_{1D} & 1\\x_{21} & \cdots & x_{2D}&1\\ \vdots & & \vdots \\ x_{N1} & \cdots & x_{ND}&1\end{bmatrix} \in \mathbb{R}^{N\times D}.$$

Then the predictions for the entire dataset can be written in one matrix product: $f(\boldsymbol{X};\boldsymbol{\theta}) = \hat{\boldsymbol{X}}\boldsymbol{\theta}$.

```python
# Each x_i is np.array of shape (D,)
x_list = [x1, x2, ..., xN]

X = np.stack(x_list, axis=0)
print(X.shape)  # (N, D)

X_hat = np.hstack([
    X, np.ones((N, 1))
])
print(X_hat.shape)  # (N, D+1)

theta = # np.array of shape (D+1,)

def f(X_hat, theta):
    return X_hat @ theta
```

### Squared Error in Matrix Form

Stack the targets $y_n$ into a vector $\boldsymbol{y} = [y_1, \dots, y_N]^\top \in \mathbb{R}^N$. The squared-error loss can then be rewritten and expanded:

$$\mathcal{L}(\boldsymbol{\theta}, \mathcal{D}) = \frac{1}{2}\sum_{n=1}^N \big(f(x_n;\boldsymbol{\theta}) - y_n\big)^2 = \frac{1}{2}\lVert \hat{\boldsymbol{X}}\boldsymbol{\theta} - \boldsymbol{y}\rVert^2$$ $$= \frac{1}{2}\big(\hat{\boldsymbol{X}}\boldsymbol{\theta} - \boldsymbol{y}\big)^\top\big(\hat{\boldsymbol{X}}\boldsymbol{\theta} - \boldsymbol{y}\big)$$ $$= \frac{1}{2}\boldsymbol{\theta}^\top\hat{\boldsymbol{X}}^\top\hat{\boldsymbol{X}}\boldsymbol{\theta} - \underbrace{\boldsymbol{y}^\top\hat{\boldsymbol{X}}\boldsymbol{\theta}}_{\boldsymbol{\theta}^\top\hat{\boldsymbol{X}}^\top\boldsymbol{y}} + \frac{1}{2}\boldsymbol{y}^\top\boldsymbol{y}$$

This is a quadratic function of $\boldsymbol{\theta}$, which is why its contour plot is bowl-shaped (a paraboloid) with a single minimum.

### The Normal Equation (Closed-Form Solution)

Taking the gradient of $\mathcal{L}(\boldsymbol{\theta}, \mathcal{D})$ with respect to $\boldsymbol{\theta}$:

$$\nabla_{\boldsymbol{\theta}} \mathcal{L}(\boldsymbol{\theta}, \mathcal{D}) = \hat{\boldsymbol{X}}^\top\hat{\boldsymbol{X}}\boldsymbol{\theta} - \hat{\boldsymbol{X}}^\top\boldsymbol{y}$$

Setting this to the zero vector and solving for $\boldsymbol{\theta}$:

$$\hat{\boldsymbol{X}}^\top\hat{\boldsymbol{X}}\boldsymbol{\theta} - \hat{\boldsymbol{X}}^\top\boldsymbol{y} = \boldsymbol{0}$$ $$\hat{\boldsymbol{X}}^\top\hat{\boldsymbol{X}}\boldsymbol{\theta} = \hat{\boldsymbol{X}}^\top\boldsymbol{y}$$ $$\boldsymbol{\theta} = \big(\hat{\boldsymbol{X}}^\top\hat{\boldsymbol{X}}\big)^{-1}\hat{\boldsymbol{X}}^\top\boldsymbol{y}$$

This is the **normal equation** — a closed-form (no iteration needed) solution for the optimal $\boldsymbol{\theta}$ under squared-error loss, i.e. Ordinary Least Squares.

> **Context (not explicit on the slides, but important for using this correctly):** the inverse $\big(\hat{\boldsymbol{X}}^\top\hat{\boldsymbol{X}}\big)^{-1}$ only exists when $\hat{\boldsymbol{X}}$ has **full column rank** — i.e. no feature is an exact linear combination of the others (no perfect multicollinearity), and there are at least as many data points as parameters ($N \geq D+1$). When this fails (or is close to failing, i.e. near-collinear features), $\hat{\boldsymbol{X}}^\top\hat{\boldsymbol{X}}$ is singular or ill-conditioned, and the normal equation breaks down or becomes numerically unstable — this is one motivation for regularized variants (e.g. ridge regression), which are likely covered in a later lecture.

## Handling Nonlinear Patterns: Basis Functions

### Motivation

The plain linear model $f(x;\boldsymbol{\theta}) = \theta_1 x + \theta_2$ can only fit straight lines, so it fails to capture curved/nonlinear relationships in $x$ — e.g., the number of people in a weight room over the course of a day rises, peaks, and falls, which no single straight line can trace well.

### Polynomial Basis Functions

Extend the function form to a polynomial in $x$:

$$f(x;\boldsymbol{\theta}) = \theta_0  \theta_1 x + \theta_2 x^2 + \dots + \theta_P x^P = \begin{bmatrix}\theta_0\\\theta_1\\\vdots\\\theta_P\end{bmatrix}^\top\begin{bmatrix}1\\x\\\vdots\\x^P\end{bmatrix} = \boldsymbol{\theta}^\top \phi(x)$$

where $\phi(x) = [1, x, x^2, \dots, x^P]^\top$ is a vector of **basis functions**.
**The key insight:** this model is _still_ linear regression, because $f$ is still **linear in $\boldsymbol{\theta}$** — it is only nonlinear in $x$. Consequently, none of the machinery from Steps 2–3 needs to change: we simply replace $\hat{\boldsymbol{x}}$ with $\phi(x)$ everywhere (including in $\hat{\boldsymbol{X}}$), and the exact same normal equation $\boldsymbol{\theta} = (\hat{\boldsymbol{X}}^\top\hat{\boldsymbol{X}})^{-1}\hat{\boldsymbol{X}}^\top\boldsymbol{y}$ still applies, just with $\hat{\boldsymbol{X}}$'s rows built from $\phi(x_n)$ instead of $[x_n, 1]$.

> **Context:** polynomial features are just one choice of basis function. In general $\phi(x)$ can be _any_ fixed, chosen-in-advance nonlinear transform of $x$ (e.g. $\sin(x)$, $\log(x)$, radial basis functions, etc.) — this generalization is what lets "linear" regression fit highly nonlinear curves, as long as the transform is chosen ahead of time and the parameters $\boldsymbol{\theta}$ still enter linearly.

## Summary

- **Supervised learning**: learning a function $f$ that maps $x$ to $y$.
- **Main ingredients** (the general recipe):
    1. Choose a function form.
    2. Define a loss function.
    3. Find a least-bad (i.e. optimal) function.
- **Linear regression** is a special case of supervised learning where $y \in \mathbb{R}$ and $f$ is linear in $\boldsymbol{\theta}$.
    - Nonlinear patterns in $x$ can still be handled, via basis functions $\phi(\boldsymbol{x})$.
