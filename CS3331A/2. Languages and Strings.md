## Why We Need This Framework

Real problems in computing (lexical analysis, parsing, optimization, termination checking, interpretation) look very different from each other on the surface. To reason about all of them with one set of tools, the theory of computation recasts every problem as an instance of **language recognition**: given a language $L$ and a string $w$, decide whether $w \in L$.

This only works if we first pin down precisely what a "string" and a "language" are.

## Strings

A **string** is a finite (possibly empty) sequence of symbols drawn from an **alphabet** $\Sigma$ (a finite set of symbols).

- $\varepsilon$ denotes the **empty string** (length 0).
- $\Sigma^*$ is the set of _all_ possible strings over $\Sigma$, including $\varepsilon$.

|Alphabet name|Symbols|Example strings|
|---|---|---|
|English alphabet|{a, b, c, …, z}|ε, aabbcg, aaaaa|
|Binary alphabet|{0, 1}|ε, 0, 001100|

The alphabet doesn't have to be letters — it can be any finite symbol set (binary digits, musical notation, etc.). This generality is what lets the same theory describe programming languages, DNA sequences, or network protocols later on.

### Functions on Strings

- **Length**: $|s|$ = number of symbols in $s$.
    - $|\varepsilon| = 0$
    - $|1001101| = 7$
- **Symbol count**: $#_c(s)$ = number of times character $c$ occurs in $s$.
    - $#_a(\texttt{abbaaa}) = 4$
- **Concatenation**: $st$ = the string formed by joining $s$ then $t$.
    - If $x = \texttt{good}$, $y = \texttt{bye}$, then $xy = \texttt{goodbye}$.
    - $|xy| = |x| + |y|$
    - $\varepsilon$ is the identity: $\forall x\ (x\varepsilon = \varepsilon x = x)$
    - Concatenation is associative: $\forall s,t,w\ ((st)w = s(tw))$
- **Repetition (power)**: for a string $w$ and natural number $i$:
    - $w^0 = \varepsilon$
    - $w^{i+1} = w^i w$
    - Examples: $a^3 = \texttt{aaa}$, $(\texttt{bye})^2 = \texttt{byebye}$, $a^0b^3 = \texttt{bbb}$
- **Reverse**: $w^R$ is $w$ written backwards, defined recursively:
    - if $|w| = 0$, $w^R = w = \varepsilon$
    - if $|w| \geq 1$, then $w = ua$ for some symbol $a$ and string $u$; define $w^R = a,u^R$

**Theorem 2.1**: $(wx)^R = x^R w^R$ for all strings $w, x$.

_Proof (induction on $|x|$)_:

- Base case $|x|=0$: $x = \varepsilon$, so $(wx)^R = (w\varepsilon)^R = w^R = \varepsilon^R w^R = x^R w^R$.
- Inductive step: assume true for $|x| = n$. Let $|x| = n+1$, so $x = ua$ for a symbol $a$ and $|u| = n$. Then: $$(wx)^R = (w(ua))^R = ((wu)a)^R = a(wu)^R = a(u^Rw^R) = (au^R)w^R = (ua)^Rw^R = x^Rw^R$$

This kind of "peel off one symbol, apply the induction hypothesis, reassemble" proof pattern recurs throughout the course — it's the standard way to prove facts about all strings without needing to check infinitely many cases individually.

### Relations on Strings

- **Substring**: `aaa` is a substring of `aaabbbaaa`; `aaaaaa` is not. Every string is a substring of itself; $\varepsilon$ is a substring of every string.
- **Proper substring**: a substring that isn't the whole string.
- **Prefix**: $s$ is a prefix of $t$ iff $\exists x \in \Sigma^*\ (t = sx)$.
    - Prefixes of `abba`: $\varepsilon$, `a`, `ab`, `abb`, `abba`.
    - Proper prefixes of `abba`: $\varepsilon$, `a`, `ab`, `abb` (i.e., prefix minus the string itself).
- **Suffix**: $s$ is a suffix of $t$ iff $\exists x \in \Sigma^*\ (t = xs)$.
    - Suffixes of `abba`: $\varepsilon$, `a`, `ba`, `bba`, `abba`.
    - Proper suffixes: $\varepsilon$, `a`, `ba`, `bba`.

## Languages

A **language** is a (finite or infinite) set of strings over a finite alphabet $\Sigma$.

Examples over $\Sigma = {a, b}$:

- $\emptyset$ (the empty language — contains no strings)
- ${\varepsilon}$ (contains exactly one string, the empty string — **not the same as $\emptyset$**)
- ${a, b}$
- ${\varepsilon, a, aa, aaa, aaaa, aaaaa}$
- $\Sigma^*$ itself — infinite, contains $\varepsilon, a, b, ab, ababaa, \ldots$

### Defining Languages Precisely

Set-builder notation is used to define languages exactly, e.g.: $$L = {x \in {a,b}^* : \text{all } a\text{'s precede all } b\text{'s}}$$ Here $\varepsilon, a, aa, aabbb, bb \in L$, but $aba, ba, abc \notin L$.

**The perils of using English**: natural-language descriptions of a language are often ambiguous or imprecise. For example, a language defined as pairs "$x\#y$ where $y$ is the square of $x$" needs careful specification of what counts as a valid encoding (are `3#8`, `12`, `12#12#12`, or bare `#` in the language?). Formal set-builder definitions force you to resolve these edge cases explicitly — this precision matters enormously once you start building machines or proofs around a language.

Some languages are easy to state but impossible to decide algorithmically, e.g.: $$L = {w : w \text{ is a C program that halts on all inputs}}$$ This is well-specified (every string is either such a program or not), but — as later chapters show — there is no algorithm that can decide membership in this language for every input. Well-defined does not imply decidable.

### Enumeration

Since languages are sets of strings, they can be **enumerated** (listed out). The most useful order is **lexicographic order**: shortest strings first, and within a given length, dictionary order. This is preferred over an arbitrary listing because it guarantees every string eventually appears at a finite position in the list.

### How Large Can a Language Be?

- Smallest: $\emptyset$, cardinality 0.
- Largest: $\Sigma^*$.

**Theorem**: If $\Sigma \neq \emptyset$, then $\Sigma^*$ is countably infinite.

_Proof idea_: Lexicographic enumeration (all length-0 strings, then length-1, then length-2, …) lists every string in $\Sigma^*$ at some finite position, since no string is infinitely long. An infinite set with such an enumeration is countably infinite.

**Consequence**: every language is either finite or countably infinite (since every language is a subset of the countably infinite $\Sigma^*$).

**Theorem**: If $\Sigma \neq \emptyset$, the set of _all possible languages_ over $\Sigma$ — i.e., $\mathcal{P}(\Sigma^*)$, the power set of $\Sigma^*$ — is **uncountably infinite**.

This follows from the general fact that the power set of any countably infinite set is uncountable (provable by **diagonalization**, the same technique Cantor used to show the irrationals are uncountable: assume a countable list of all irrationals $n_1, n_2, n_3, \ldots$, then construct a new number $N$ whose $i$th decimal digit differs from the $i$th digit of $n_i$ — so $N$ cannot equal any $n_i$, contradicting the assumption that the list was complete).

**Why this matters**: There are uncountably many languages but only countably many possible finite descriptions (grammars, programs, Turing machines — each is just a finite string). This is a purely counting argument that _some_ languages must be undecidable, even before you construct a specific undecidable language like the halting problem — there simply aren't enough algorithms to go around.

## Functions on Languages

**Set operations** (languages are sets, so ordinary set operations apply): union, intersection, complement.

**Language-specific operations**:

### Concatenation of Languages

$$L_1 L_2 = {w \in \Sigma^* : \exists s \in L_1\ (\exists t \in L_2\ (w = st))}$$ Example: $L_1 = {\texttt{cat}, \texttt{dog}}$, $L_2 = {\texttt{apple}, \texttt{pear}}$ → $L_1L_2 = {\texttt{catapple}, \texttt{catpear}, \texttt{dogapple}, \texttt{dogpear}}$

- ${\varepsilon}$ is the identity: $L{\varepsilon} = {\varepsilon}L = L$.
- $\emptyset$ is a zero: $L\emptyset = \emptyset L = \emptyset$.

**Caution with variables**: when a language definition uses a bound variable (like $n$) inside an expression involving concatenation, the variable's scope is the _entire_ expression, not each factor independently. So if $L_1 = {a^n : n \geq 0}$ and $L_2 = {b^n : n \geq 0}$, then $$L_1 L_2 = {a^n b^m : n, m \geq 0} \neq {a^n b^n : n \geq 0}$$ because concatenating the _languages_ pairs every string of $L_1$ with every string of $L_2$ independently — $n$ and $m$ are not linked just because they reused the same letter in the separate definitions. This is a common source of errors.

### Kleene Star

$$L^* = {\varepsilon} \cup {w \in \Sigma^* : \exists k \geq 1\ (\exists w_1, \ldots, w_k \in L\ (w = w_1w_2\cdots w_k))}$$ i.e., all strings formed by concatenating zero or more strings from $L$.

Example: $L = {\texttt{dog}, \texttt{cat}, \texttt{fish}}$ → $L^* = {\varepsilon, \texttt{dog}, \texttt{cat}, \texttt{fish}, \texttt{dogdog}, \texttt{dogcat}, \texttt{fishcatfish}, \ldots}$

### The $^+$ Operator

$$L^+ = LL^*$$ This is $L^*$ but requiring **at least one** string from $L$ (i.e., excludes the "zero copies" case). If $\varepsilon \notin L$, then $L^+ = L^* - {\varepsilon}$. $L^+$ is called the **closure of $L$ under concatenation**.

**Theorem**: $(L_1 L_2)^R = L_2^R L_1^R$ (note the order flips, just like matrix transposes or reversing a queue of actions).

_Proof_: Using Theorem 2.1 ($\forall x,y\ ((xy)^R = y^Rx^R)$): $$(L_1L_2)^R = {(xy)^R : x \in L_1, y \in L_2} = {y^Rx^R : x \in L_1, y \in L_2} = L_2^R L_1^R$$

## Syntax vs. Semantics

A language as defined so far is purely **syntactic** — a set of strings with a certain _form_, with no inherent _meaning_. For example, $A^nB^n = {a^nb^n : n \geq 0}$ is just a set of strings; whether those strings "mean" anything depends on an external **semantic interpretation function** layered on top.

- **Syntax** = form (what strings are well-formed / in the language)
- **Semantics** = meaning (what those strings represent or do)

This distinction matters for real formal languages:

- **Natural languages** (English, DNA) have semantics that are hard to pin down formally.
- **Formal languages** (programming languages, network protocols, database query languages, HTML, BNF grammars) have well-defined semantic interpretation functions — e.g., a compiler assigns meaning (an executable action) to syntactically valid program text.

This sets up the rest of the course's separation of concerns: first nail down which strings are syntactically valid (language recognition), then separately worry about what they mean.
